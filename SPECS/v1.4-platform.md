# v1.4 Specification — Platform Expansion

## Overview
Take Study Hub everywhere: mobile-first PWA, desktop power-user features, browser extension, and embeddable widgets.

---

## 1. Mobile-First PWA (Capacitor + Native)

### Offline-First Architecture
```
┌─────────────────────────────────────────┐
│           Service Worker                │
│  (Workbox: precache, runtime caching)   │
└──────────────┬──────────────────────────┘
               │
    ┌──────────┴──────────┐
    ▼                     ▼
IndexedDB            Background Sync
(local mutations)    (queue → push)
    │                     │
    └──────────┬──────────┘
               ▼
        Supabase Realtime
        (conflict-free merge)
```

### Data Layer (RxDB / WatermelonDB)
- Reactive queries → UI auto-updates
- Sync adapter for Supabase (custom)
- Conflict resolution: Automerge CRDT for collaborative data; LWW for user prefs

### Native Capabilities (Capacitor Plugins)
| Feature | Plugin | Fallback |
|---------|--------|----------|
| Push Notifications | `@capacitor/push-notifications` | Web Push |
| Haptics | `@capacitor/haptics` | `navigator.vibrate` |
| Local Notifications | `@capacitor/local-notifications` | Service Worker |
| File System | `@capacitor/filesystem` | File System Access API |
| Camera/Scanner | `@capacitor/camera` + ML Kit | `getUserMedia` + Tesseract.js |
| Biometric Auth | `@capacitor/biometric-auth` | WebAuthn |
| Share | `@capacitor/share` | Web Share API |
| Background Mode | `capacitor-background-mode` | Periodic Background Sync |

### Mobile-Specific UI
- **Bottom Nav** — 5 tabs (Dashboard, Sessions, Flashcards, AI, More)
- **Swipe Gestures** — Tab switch, card flip, delete undo
- **Pull-to-Refresh** — All list views
- **Safe Area** — Notch/Dynamic Island handling
- **Landscape** — Optimized flashcard/calculator views

### App Store Builds (Optional)
- **iOS** — TestFlight → App Store (requires Apple Dev $99/yr)
- **Android** — Play Console (one-time $25)
- **Alternative** — PWA only (current), or distribute .ipa/.apk directly

## 2. Desktop Power User (Electron)

### Global Shortcuts (Register at login)
| Shortcut | Action | Configurable |
|----------|--------|--------------|
| `Ctrl+Shift+Space` | Quick capture (note/task/flashcard) | Yes |
| `Ctrl+Shift+T` | Start/stop Pomodoro | Yes |
| `Ctrl+Shift+F` | Global search (Command Palette) | Yes |
| `Ctrl+Shift+N` | New window | No |

### Menu Bar / Tray App
- **Always running** (hidden window)
- **Tray menu**: Timer status, quick actions, next task
- **Click** → Popover (300x400) with mini dashboard
- **Right-click** → Full menu (Settings, Quit)

### Multi-Monitor Layouts
- **Save Layout** — Window positions, sizes, tabs per window
- **Profiles** — "Study", "Lecture", "Review" (switch via menu/shortcut)
- **Persist** — `electron-window-state` extended for multi-window

### Plugin System (User Scripts)
```
~/.study-hub/plugins/
  ├── my-generator/
  │   ├── manifest.json    # {name, version, tabs[], apiVersion}
  │   ├── index.js         # Exports: generators[], hooks{}
  │   └── styles.css
  └── anki-importer/
      └── ...
```

**API Surface** (exposed via preload):
```js
window.StudyHubPlugins = {
  registerGenerator: (def) => {},
  registerImporter: (def) => {},
  on: (event, handler) => {},  // 'session:start', 'card:review', 'note:save'
  state: { get: (path), set: (path, val), subscribe: (path, cb) },
  ui: { addTab: (def), showToast: (msg), openModal: (comp) },
  storage: { local: {}, cloud: {} }
}
```

**Security**: Plugins run in isolated context (vm2 or separate Electron UtilityProcess); no Node.js access; message-passing only.

## 3. Chrome Extension (MV3)

### Features
| Feature | Implementation |
|---------|----------------|
| **Right-click → "Add to Study Hub"** | Context menu: selection, image, link, page |
| **Side Panel** | `side_panel.setOptions` — mini dashboard, quick capture |
| **Command** | `Ctrl+Shift+Y` → open side panel |
| **Content Script** | Detect quiz pages (Khan, Coursera, etc.) → "Import as Flashcards" |
| **PDF Viewer** | Embed in extension popup for PDF chat |

### Permissions
```json
{
  "permissions": ["contextMenus", "sidePanel", "storage", "activeTab", "scripting"],
  "host_permissions": ["https://study-hub-plum-omega.vercel.app/*"],
  "background": { "service_worker": "background.js" }
}
```

### Data Flow
1. User selects text → right-click → "Create Flashcard"
2. Extension opens side panel with pre-filled form
3. Submit → POST to `/api/extension/capture` (auth via cookie/header)
4. Response → toast + sync to local state

## 4. Notion/Obsidian/Anki Import Wizards

### Notion
- **OAuth** — Notion integration (user installs to workspace)
- **Sync** — Pull databases: Flashcards, Notes, Tasks, Calendar
- **Mapping** — UI to map Notion properties → Study Hub fields
- **Schedule** — One-time or periodic (daily cron)

### Obsidian
- **Local Vault** — File System Access API (browser) or native dialog (Electron)
- **Parse** — Markdown + frontmatter + wikilinks + canvas
- **Map** — `#flashcard` tag → deck; `due:` property → SRS

### Anki
- **`.apkg` Import** — JSZip + SQLite parse (sql.js WASM)
- **Mapping** — Note types → Study Hub card types; media extraction
- **Scheduler Sync** — Import intervals/due dates; map to FSRS params

### UI: Settings → Import Data
- Source selector → Auth/Select → Field mapping preview → Run → Report

## 5. Public Sharing & Embeddable Widgets

### Publish Notes/Guides
- **Settings → Share** → Generate public slug (`/s/abc123`)
- **Options**: Allow comments, allow fork, password protect, expire date
- **SEO** — Meta tags, JSON-LD (Schema.org: LearningResource)
- **Analytics** — Views, forks, time-on-page (plausible.io self-hosted)

### Embeddable Flashcard Reviewer
```html
<iframe src="https://study-hub-plum-omega.vercel.app/embed/flashcards/deck-id"
        width="100%" height="400" frameborder="0"></iframe>
```
- **Config** — `?mode=review&theme=dark&autoplay=1`
- **PostMessage** — Parent receives `card:answered`, `session:complete`

### Embeddable Study Plan
- Read-only timeline with progress bars
- Use case: Notion embed, personal website, LMS

## 9. Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Capacitor plugin maintenance | Pin versions; test on every OS release; fallback to web APIs |
| Electron plugin security | UtilityProcess isolation; CSP; no Node integration in plugins |
| Extension MV3 limits | Service worker lifecycle; offscreen documents for long tasks |
| Sync conflicts (mobile) | Automerge CRDT; user-visible conflict UI for manual resolve |
| App Store rejection | Follow guidelines; prepare appeals; PWA as fallback |
| Bundle size (mobile) | Code-split by tab; lazy-load heavy features (labs, AI) |
